Công cụ Gán nhãn Ảnh Nhiệt Định hướng

Vui lòng chọn thư mục chứa ảnh hoặc chọn danh sách tệp ảnh (.jpg, .jpeg, .png) để bắt đầu phiên gán nhãn.

Hướng dẫn nhanh:
• Hỗ trợ đọc tệp classes.txt nếu có trong thư mục hoặc danh sách tệp đã chọn.
• Công cụ vẽ: N vẽ chữ nhật 3 điểm, Q vẽ tứ giác 4 đỉnh tự do.
• Chế độ sửa (V): kéo tự do từng đỉnh (giữ Shift khi kéo góc để giữ hình chữ nhật), nhấn R để ép thành chữ nhật.
• Ảnh chỉ được giữ trong bộ nhớ tạm khi làm việc; nhãn và nhật ký lưu tự động theo từng phiên.
